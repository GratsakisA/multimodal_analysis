# Multimodal Analysis

⚠️ **Status**: Early development (not yet released)

## Overview
`multimodal_analysis` processes and analyzes behavioral data from multimodal <b>audiovisual</b> experiments. It provides streamlined tools for comparing behavior across conditions, modalities, and subjects, with built-in visualization and database support.

## Features

- Behavioral data processing and analysis
- Analysis across experimental modalities
- Analysis across animals
- Database integration
- Configurable behavioral sessions
- Data visualization
- Reusable analysis functions and utilities
